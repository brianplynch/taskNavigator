# Readme

Task Navigator

## Installation

1. Copy the repository to any location in the local drive
2. Set the [taskNavConfig](taskNavConfig.ini) file configurable attributes (e.g. vault path)
3. Create the Windows shortcut:
    1. target: "python-path" taskNavigator.py
    2. start in: task navigator path/taskNavigator
4. Set the [filtered_list_frame_attributes](ux/filtered_list_frame_attributes.ini) file configurable attributes (e.g. font and colors)


## Dependencies

Task Navigator works with a standard Python 3 installation (with Tk). Task Navigator does not have separately installed package dependencies.
